# Phase 22 — Evidence-backed model PPA study scorecard

This module **reports audited results**, not mock metrics, model superiority or
signoff PPA. It does not call LLMs, simulators or EDA. It reads an existing
two-model Pilot only after Phase 21 post-selection audits are complete.

## Workflow

Run a real two-model pilot using `chiprd.pilot_runner --execute`.
After optimization concludes, choose an independent seed and run the
`chiprd.pilot_audit` Verilator/analytic-oracle check. Then produce the final,
offline evidence-backed study:

```bash
python3 -m chiprd.study_scorecard \
  --pilot-dir artifacts/real-model-pilots/first-two-models \
  --output artifacts/real-model-pilots/first-two-models/study_scorecard.json
```

The output path must not already exist. The command independently recomputes
both Phase 17 campaigns and their comparability conditions, checks the stored
comparison, validates the post-selection audit summary and **each** archived
per-run audit file against the selected candidate SHA-256, originating loop
report SHA-256 and audit seed/vector count.

## What is counted

Per model, the denominator is **all requested runs**, including missing,
crashed and failed attempts:

| Metric | Definition |
| --- | --- |
| `ppa_evidence_runs` | Runs with archival PPA evidence passing comparison checks |
| `ppa_improved_runs` | Runs where the selected timing-feasible mapped area beats the Golden baseline |
| `post_selection_passed_runs` | Runs where the frozen RTL candidate passes a new-seed numerical audit |
| `audited_improved_runs` | Intersection of PPA improvement **and** passing post-selection audit |
| `audited_improvement_rate` | `audited_improved_runs / runs_requested`; never divide only by successful attempts |

A missing audit or an audit failure never counts as an audited improvement.
A fully supported study can contain **zero genuine area improvements**—that is
a valid empirical finding rather than a reason to manufacture a winner.
A study with incomplete/unverified runs is explicitly marked `incomplete`.
Neither the comparative metrics nor the scorecard asserts model superiority.

No actual model measurements are bundled in the repository. Offline tests use
fabricated fixtures solely to verify integrity and arithmetic.

## Limitations

- Hashes detect inconsistent evidence but do not prove the result was
  generated by a trusted machine or independently attested toolchain.
- Independent seed means the researcher chooses the seed *after* optimizing;
  it is not a private holdout. A sampled simulation cannot guarantee complete
  functional equivalence. The six public gates still apply.
- Liberty-area and ideal-clock OpenSTA WNS are pre-layout estimates, not routed
  physical PPA or signoff metrics.
- Small-sample descriptive rates do not imply statistical significance.
- Raw Agent artifacts may contain prompts, RTL and sensitive text; review
  before publication.
